Задание
Вам необходимо спроектировать и задокументировать API, используя ИИ как помощника при формулировании описаний.

Рассматривается API для управления задачами (Task Manager).
API должно включать:

Эндпоинт создания задачи
Эндпоинт получения задачи по идентификатору
Хранение данных реализуется без использования базы данных (допускается временное хранение в памяти).
Что необходимо сделать:

Реализовать API на FastAPI
Создайте минимальное приложение FastAPI, включающее:
Эндпоинт создания задачи
HTTP-метод: POST
Путь: /tasks
Входные данные (JSON body):
title — строка, обязательное поле, от 3 до 100 символов
description — строка, необязательное поле
priority — целое число, обязательное поле, значения от 1 до 5
Ответ:
HTTP 201 Created
JSON с данными созданной задачи и её идентификатором
Эндпоинт получения задачи
HTTP-метод: GET
Путь: /tasks/{task_id}
Ответ:
HTTP 200 OK — если задача найдена
HTTP 404 Not Found — если задача отсутствует
Задокументировать API с использованием ИИ
С помощью ИИ необходимо:
сформулировать описания эндпоинтов (summary, description);
описать параметры запросов и их назначение;
оформить описание моделей данных (Pydantic);
уточнить возможные ошибки и их смысл.
ИИ используется только для генерации и улучшения текстовых описаний, а не для автоматического проектирования логики API.
Проверить документацию в Swagger UI
После добавления описаний:
запустите приложение;
откройте Swagger UI;
убедитесь, что:
описания читаемы и однозначны;
параметры и модели отображаются корректно;
ошибки задокументированы явно.
Инструкция к выполнению
Реализуйте минимальный API без расширенных описаний.
Сформулируйте промпты для ИИ:
a. для описания эндпоинтов;
b. для описания моделей данных;
c. для формулировки ошибок.
Добавьте сгенерированные описания в код FastAPI.
Проверьте результат в Swagger UI.
При необходимости скорректируйте описания вручную, устранив неточности.
